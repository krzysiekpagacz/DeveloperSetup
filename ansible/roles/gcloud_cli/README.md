# gcloud_cli

## General

Adds the Google Cloud apt repository (with its signing key) and installs the Google Cloud CLI, then verifies the installation by printing its version.

## What it installs

| Tool             | Version      | Description                                                |
| ---------------- | ------------ | ---------------------------------------------------------- |
| google-cloud-cli | latest (apt) | Google Cloud SDK CLI (`gcloud`) for managing GCP resources |
