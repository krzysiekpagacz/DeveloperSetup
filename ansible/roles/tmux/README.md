# tmux

## General

Installs tmux, deploys the shared config from `files/tmux.conf` to `~/.config/tmux/tmux.conf`, and auto-attaches every new terminal to a `default` tmux session.

## What it installs

| Tool | Version      | Description          |
| ---- | ------------ | -------------------- |
| tmux | latest (apt) | Terminal multiplexer |
