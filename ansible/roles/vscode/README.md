# vscode

## General

Installs VS Code (desktop) via the external `gantsign.visual-studio-code` role, removes the legacy Microsoft apt repo, and writes baseline user settings to `~/.config/Code/User/settings.json`.

## What it installs

| Tool               | Version                                         | Description        |
| ------------------ | ----------------------------------------------- | ------------------ |
| Visual Studio Code | latest (apt, via `gantsign.visual-studio-code`) | Source code editor |
