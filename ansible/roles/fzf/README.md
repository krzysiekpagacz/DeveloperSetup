# fzf

## General

Installs fzf and adds its key bindings to `.bashrc` (source of `/usr/share/doc/fzf/examples/key-bindings.<shell>`).

## What it installs

| Tool | Version      | Description                                                               |
| ---- | ------------ | ------------------------------------------------------------------------- |
| fzf  | latest (apt) | Command-line fuzzy finder, wired into bash via Ctrl-R/Ctrl-T key bindings |
